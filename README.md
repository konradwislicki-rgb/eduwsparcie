# eduwsparcie.pl

Repozytorium zawiera kod źródłowy projektu **eduwsparcie.pl** – platformy edukacyjnej łączącej:

- stronę główną opartą o **WordPress + Elementor** (blog, aktualności, treści edukacyjne),
- interaktywne podstrony tworzone w **HTML / CSS / JavaScript**,
- projekty edukacyjne realizowane wspólnie z uczniami (np. gry, ćwiczenia, narzędzia matematyczne).

---

## 📌 Struktura projektu

Proponowana struktura katalogów:
/wordpress/        – motyw, child theme, własne pluginy, elementy WP
/html/             – podstrony statyczne HTML/CSS/JS
/projects/         – projekty edukacyjne tworzone z uczniami
/assets/           – wspólne zasoby (grafiki, ikony, style)
/docs/             – dokumentacja, materiały pomocnicze
